# 🗄️ Bases de Datos I - Grupo I4

Repositorio académico y portafolio de proyectos para la materia de **Bases de Datos I** (UAGRM). Este espacio documenta el desarrollo paso a paso de una base de datos relacional para un negocio real, aplicando las mejores prácticas de modelado y SQL.

---

## 🎯 Objetivos del Proyecto
* Comprender y aplicar los fundamentos del diseño de bases de datos relacionales.
* Pasar de un problema del mundo real (recolección de requisitos) a un modelo conceptual y lógico.
* Aplicar las reglas de Normalización (1FN, 2FN, 3FN) para garantizar la integridad de los datos.
* Implementar el diseño en un motor de base de datos usando scripts SQL.

## 🛠️ Tecnologías y Herramientas
* **Modelado y Diseño:** Draw.io
* **Control de Versiones:** Git & GitHub
* **Lenguaje:** SQL (DDL, DML, Consultas avanzadas)
* **Documentación:** Markdown
